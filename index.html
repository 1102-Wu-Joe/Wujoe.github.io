About the game

Flappy Chicken brings the classic one-button arcade formula into 3D. The player controls a chicken that falls under gravity and jumps on a keypress, dodging a continuous stream of pipe obstacles while racking up points.

Built as a demonstration of a component-based entity system — each object is assembled from reusable components: Transform, Physics, DrawModel, Input, and Collider. The architecture mirrors real engine ECS patterns in a lightweight, self-contained codebase.

How to play

Download and extract the zip. Keep all folders next to the .exe, then double-click to launch.

Space Make the chicken flap upward
Mouse Click buttons in menus
Alt + F4 Quit the game

Built with

Written in C++ using raylib as the graphics and audio foundation. UI via raygui, skybox via custom GLSL shaders, and built with CMake.

C++ raylib 5.0 raylib-cpp raygui GLSL shaders OpenGL CMake
